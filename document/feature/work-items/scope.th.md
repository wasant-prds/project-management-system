| กรณีที่ 6 | **ฟิลด์** ของโมดัลสร้าง/แก้ไข (ฟอร์ม Description) ไม่เปลี่ยน **โครงโมดัล** ตามกรณีที่ 9 |
| ส่งออก | ไม่เพิ่ม UX จัดกลุ่ม CSV/Markdown ส่งออกรายการที่มองเห็นตามเดิม |
| กรณีที่ 7 จำสถานะ | ไม่เก็บสถานะขยายใน `localStorage` รีเซ็ตเมื่อเปลี่ยนปี เดือน โครงการ คำค้น แท็บชนิดงาน หรือการเรียง |
| กรณีที่ 7 บัตร | บัตรไม่ย่อ ไม่ใช้โหมดแถวเดียวแบบย่อ ฟิลด์เดิม ตัด/ขึ้นบรรทัดใหม่เท่านั้น |

| แพลตฟอร์ม | ไม่เพิ่ม REST ใหม่ ไม่เปลี่ยนสคีมา Prisma ไม่เพิ่มบริการ Docker |

## 4. หมายเหตุทางเทคนิคของกรณีในขอบเขต

### กรณีที่ 1 — ปี

- ค่าเริ่มต้น: `String(new Date().getFullYear())` (เวลาท้องถิ่นของเบราว์เซอร์)
- รายการปี = `all` + ปีปัจจุบัน + ปีที่พบในข้อมูลที่โหลด ไม่ซ้ำ เรียงจากใหม่ไปเก่า

### กรณีที่ 2 และ 3 — ฟิลด์เรียง

- เทียบความใหม่ด้วย `updatedAt`
- รายการที่ไม่มี `updatedAt` ถือว่าเก่าสุด
- การเรียงวันครบกำหนด: รายการที่ไม่มีวันครบกำหนดอยู่ท้ายกลุ่มตามแผน

### กรณีที่ 5 — ขอบวันที่

- เทียบวันครบกำหนดด้วย **วันที่ปฏิทินท้องถิ่น** ไม่ใช่เวลา UTC
- เกินกำหนด: วันครบกำหนด **&lt; วันนี้**
- ใกล้ครบกำหนด: วันครบกำหนด **≥ วันนี้** และ **เดือนปฏิทินเดียวกับวันนี้**
- ตามแผน: ยังไม่เสร็จ ไม่เกินกำหนด ไม่ใกล้ครบกำหนด

### กรณีที่ 6 — ไฟล์

- แก้แถวข้อมูลเมตาและโครงโมดัลร่วมที่ `components/page/work-items/work-item-view-dialog.tsx`
- ตารางมาร์กดาวน์: `components/page/work-items/work-item-description.tsx` (GFM `| col |` / `| --- |` พรีวิวเดียวกันบน `/daily-work`)

### กรณีที่ 9 — เลย์เอาต์หลายอุปกรณ์

- จุดพัก: โทรศัพท์ `< sm` (640px) แท็บเล็ต `sm`–`lg` (640–1023px) เดสก์ท็อป `lg+` (1024px)
- สถิติ: `grid-cols-2 sm:grid-cols-4` ลดระยะการ์ด (`gap-1 py-3` ไม่ใช้ค่าเริ่มต้น `gap-6 py-6`)
- ปุ่มส่งออก: ไอคอน + `aria-label` บนโทรศัพท์ แสดงข้อความตั้งแต่ `sm`
- ตัวกรอง: `w-full` บนโทรศัพท์ ความกว้างคงที่ตั้งแต่ `sm` แท็บชนิดงานอยู่ในแถวเลื่อนแนวนอน ตัวเลือกเป็น `flex-none`
- โครงโมดัล: `components/page/work-items/work-item-dialog-shell.ts` ความสูง `calc(100dvh − inset)` บนโทรศัพท์/แท็บเล็ต `lg:max-w-[54.6rem]` เปลือก `overflow-hidden` เลื่อนภายใน ห้ามใช้ `sm:max-w-[54.6rem]` (ล้นจอแท็บเล็ต)
- บัตร: `min-w-0` `line-clamp-2` ที่ชื่อเรื่อง ตัดชื่อผู้รับผิดชอบ ไม่ตัดฟิลด์ออก

### กรณีที่ 7 — ขยาย / ต้นไม้

- ใช้ `components/ui/collapsible.tsx` (Radix) ที่มีอยู่ ไม่สร้างบริการใหม่
- กลุ่มย่อยแรกที่มีบัตร = ถังกรณีที่ 5 แรกของโครงการนั้นที่ไม่ว่าง
- การเปิดโครงการที่เคยย่อ จะเปิดกลุ่มย่อยแรกที่มีบัตรของโครงการนั้นด้วย
- เส้นต้นไม้เป็น CSS (แกน `border` + ข้อศอก) ไม่ใช่ตัวอักษร `├──`
- การย่อขนาดระดับใน = ตัวอักษร/ระยะ/เยื้องเล็กลง ไม่ใช้ `transform: scale` หรือ CSS `zoom`

### กรณีที่ 8 — หัวกลุ่มติดหน้าจอ

- ใช้ CSS `position: sticky` ใน `main` ที่เลื่อนได้ (`top: 0` สำหรับโครงการ, `top: <ความสูงหัวโครงการ>` สำหรับกลุ่มย่อย) แถบหัวแอปเป็นพี่น้อง จึงอยู่ใต้แถบนั้น
- ห้ามห่อหัวที่ติดด้วย `overflow: hidden` (อย่าให้ `CollapsibleContent` ของ Radix ตัด)
- พื้นหลัง/เงาตอนติด ใช้เมื่อแถบถึงระยะ sticky แล้ว (ฟังสกรอลล์ของ `main`)
- ติดเฉพาะตอนที่ collapsible นั้นเปิดอยู่
