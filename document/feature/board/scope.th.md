## 2. ในขอบเขต

| กรณีธุรกิจ | ในขอบเขต |
| --- | --- |
| กรณีที่ 1 — ดูงานเป็นคอลัมน์ | คอลัมน์และการ์ดที่มีอยู่ |
| กรณีที่ 2 — เลื่อน | โครงแถบข้าง `h-svh`; `main` ของบอร์ดใช้ `overflow-hidden` กับแผง `overflow-auto` ด้านใน |
| กรณีที่ 3 — คอนทราสต์ | โทเค็นปุ่ม/แบดจ์ร่วม |
| กรณีที่ 4 — ตอบสนอง | โทเค็นแถบเครื่องมือร่วม คอลัมน์กว้างคงที่และเลื่อนข้าง |

## 3. นอกขอบเขต

| รายการ | นอกขอบเขต |
| --- | --- |
| ลากวางแล้วบันทึก | ไม่เพิ่ม API บันทึกใหม่ในรอบนี้ |

| แพลตฟอร์ม | ไม่มี REST ใหม่ ไม่เปลี่ยนสคีมา Prisma ไม่มีบริการ Docker ใหม่ |

---

## 4. บันทึกทางเทคนิค

- อย่าใส่ `overflow-y-auto` บน `main` ของบอร์ดจนเลื่อนซ้ำกับพื้นที่คอลัมน์ พื้นที่คอลัมน์ใช้ `overflow-auto` ภายในแผง `min-w-0`
- จุดตัด: โทรศัพท์ `< 640` แท็บเล็ต `640–1023` เดสก์ท็อป `1024+`
