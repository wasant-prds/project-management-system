# Projects และ Project workspace — Issue #49

Completed implementation และ isolated verification วันที่ 2026-11-13 สำหรับ `/projects` และ `/projects/[id]` ต่อจาก shared foundation #47. คงขอบเขต frontend ของ #46; ไม่เปลี่ยน API, schema, authorization, workflow statuses หรือสูตร metric

- Projects ใช้ primary action “สร้าง Project” ใน toolbar และ shared responsive dialog สำหรับ create/edit. คง Company, name, start/due, status/priority, validation และ POST/PATCH เดิม. ขณะบันทึกล็อก fields และการปิด dialog; API failure เก็บค่าเดิมและแสดงใน dialog. Escape/ยกเลิกคืน focus ไปยัง action ต้นทาง. Compact filters และ summary ใช้ semantics เดิม
- Portfolio cards แสดง Company/Project แบบตัดบรรทัดแทนตัดข้อความ. Subgrid จัด status/priority, progress, counts/hours และ due/actions ตรงแนวเมื่ออยู่แถวเดียวกัน แม้ชื่อ/จำนวนต่างขนาด. Header ยกเลิก size-query containment เฉพาะการ์ดนี้เพื่อให้ nested subgrid ทำงาน; ไม่แก้ shared Card
- Workspace มี Company/status/priority/ช่วงเวลา/progress/hours แบบกระชับ และ tabs ภาพรวม / Work Items / Daily Work / Integrations. ใช้ shared keyboard tabs และ scroll ภายใน. เมนูรอง “จัดการ Project” เปิด alert dialog ลบเดิม; pending ห้ามกดซ้ำ/ปิด และ server rejection แสดง code/message โดยไม่พาไปหน้ารายการหรือแสดง success
- Integrations แยก provider/source, enabled/approval, assignees, sync/history และรายละเอียดขั้นสูง. คง source-specific settings, token variable names, label mappings, toggle/save handlers, first-sync approval, stream, pending review, history pagination และ per-item errors เดิม. แสดงรอบล่าสุดเฉพาะ history ที่โหลดแล้ว ไม่เพิ่ม API สำหรับดึงสถานะรอบล่าสุดของทุก config
- Integrations panel ใช้ `forceMount` กับ `hidden` จึงไม่ unmount เมื่อเปลี่ยน tab. Stream, progress/results, review choices/errors, history disclosure และ config draft คงอยู่. `#integrations` เปิด tab ทั้งตอนเข้า URL และ hash navigation; เมื่อเลือก tab อื่นจะเอา hash นี้ออกเพื่อให้ตามลิงก์เดิมซ้ำได้
- Daily Work ใช้ชื่อจาก `project.workItems` จับคู่ด้วย public UUID ที่มีอยู่ใน DTO. หากไม่มีชื่อแสดง “เปิด Work Item ที่บันทึกเวลา” พร้อมลิงก์ UUID ตามสัญญา; record เดิมที่ไม่มี Work Item แสดงข้อความอธิบาย. ไม่เพิ่ม API/relations เพื่อเติมชื่อ. วันแสดงด้วย formatter ร่วม `Asia/Bangkok`; ไม่เปลี่ยน date payload หรือ persisted wall-clock
